# MVP - ONG Cão Sem Dono
Sistema Web Responsivo (PWA) desenvolvido para otimizar a triagem de candidaturas à adoção e o controle de estoque de insumos (rações e medicamentos) da ONG Cão Sem Dono.
## Tecnologias
- **Backend:** Python (FastAPI, Pydantic, Uvicorn)
- **Banco de Dados:** PostgreSQL (Supabase)
- **Frontend:** HTML5, CSS3, JavaScript (PWA)# mvp-cao-sem-dono
